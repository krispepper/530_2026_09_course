Steps to install & run project.

2. Open the repository folder.
3. Use the following command: python3 -m venv .venv
4. Use the following command: source .venv/bin/activate
5. Use the following command: pip install -r requirements.txt (if not installed already)
6. Use the following command: python {python file name}.py
